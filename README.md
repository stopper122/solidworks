# CSWA Practice Exam

A timed, self-grading practice exam laid out like the Certified SOLIDWORKS Associate (CSWA) exam. All questions and drawings are original.

**Take the exam:** https://stopper122.github.io/solidworks/

- 13 questions, 180 points, 70% to pass
- Drafting competencies, basic / intermediate / advanced part modeling, and assembly modeling
- Students model the parts in SOLIDWORKS and answer with Mass Properties (MMGS units)
- Progress is saved in the student's own browser; nothing is sent anywhere
