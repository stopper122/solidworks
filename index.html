Certified SOLIDWORKS Associate · practice simulation

Model it, measure it, answer it.

This is an original practice exam laid out like the CSWA. You read engineering drawings, build parts and an assembly in SOLIDWORKS, then use Mass Properties to answer. Keep SOLIDWORKS open in another window while you work.

SectionQuestionsPoints

Rules

  • Units are MMGS (millimeter, gram, second). Enter answers with 2 decimal places.
  • Typed answers within ±1% of the key count as correct. Use the density given on each drawing.
  • Each part comes in pairs: build it, then change the A/B values for the next question. Save a copy before you change it.
  • You can move between questions and flag any to revisit. The exam submits itself when time runs out.
  • Passing score: 70% (126 of 180).

Begin

Tips

  • Set the material first (Edit Material), then check units under Options › Document Properties.
  • Click any drawing to open it full size.
  • For the assembly, add a Coordinate System at the plate corner and pick it in Mass Properties.
